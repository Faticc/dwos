Tab дописывает имя команды или файла, повторное нажатие листает варианты.
Стрелки вверх и вниз листают последние команды, их число задаёт HISTSIZE.
Ctrl+C прерывает ожидание, Ctrl+Alt+C убивает программу, Ctrl+D - конец ввода.
edit подсвечивает Lua-код: ключевые слова, строки, числа и комментарии.
В edit Ctrl+F ищет, Ctrl+Z отменяет, Ctrl+L - переход к строке по номеру.
В edit Shift со стрелками выделяет, Ctrl+C копирует, Ctrl+U вставляет.
Со второй буквы edit сам подсказывает слово серым - Tab его принимает.
Ctrl+Space в edit открывает список вариантов: имена из файла, Lua и поля таблиц.
Ctrl+Alt+C убивает программу; process.killable(false) закрывает её от этого.
man <команда> покажет справку, а просто man - список всего, что есть.
Команды можно склеивать: ls | grep lua, а результат писать в файл: ls > список.txt.
`команда` в обратных кавычках подставляет вывод команды прямо в строку.
install переносит систему с дискеты на жёсткий диск.
update обновляет всё, что стоит: систему, игры, ролики, программы - только изменившееся.
Своя команда при каждом входе - впишите её в /home/.shrc.
Службы из /etc/rc.d включаются командой rc <имя> enable.
Экран отдаёт вызовы за бюджет тика, а видеопамять - нет: на этом держится графика системы.
sysmon рисует память, энергию и компоненты в реальном времени.
Метку диска меняет label, а посмотреть все диски можно командой df.
Если вывод длинный - добавьте | less, листать пробелом и стрелками.
get - игры и программы одной командой: get install mario, get update - обновить всё.
